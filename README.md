# yuzofatov.github.io

Личный сайт-резюме Романа Юзофатова — инженера-исследователя (вычислительная физика, ML/NN).

## Структура

```
├── index.html          # Главная страница (о себе, публикации, новости, контакты)
├── hobbies.html        # Страница хобби (бег, марафоны, наука)
├── css/
│   └── style.css       # Стили (адаптивные, с анимациями)
├── js/
│   └── main.js         # JavaScript (анимации, меню, reveal-эффекты)
├── source_files/
│   ├── fon.jpg                   # Фоновое изображение
│   ├── islands-retina-small.jpeg # Фото профиля
│   └── personal_urls.txt         # Ссылки ResearchGate, ORCID
└── .nojekyll          # Отключает обработку Jekyll на GitHub Pages
```

## Публикация на GitHub Pages

1. Создайте репозиторий `yuzofatov.github.io` (замените `yuzofatov` на ваш никнейм GitHub).
2. Загрузите все файлы в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/yuzofatov/yuzofatov.github.io.git
   git push -u origin main
   ```
3. В настройках репозитория (Settings → Pages):
   - **Source**: Deploy from a branch
   - **Branch**: `main` / `/(root)`
   - Нажмите **Save**

Сайт будет доступен по адресу `https://yuzofatov.github.io/`.

> Файл `.nojekyll` гарантирует, что GitHub Pages отдаст все файлы как есть (PDF, JPG и т.д.), без обработки Jekyll.

## Добавление забегов (JSON)

В разделе «Новости» карточки забегов автоматически генерируются из JSON-файлов в папке `run_results/`.

### Формат JSON-файла забега

Создайте новый файл в `run_results/` со следующим форматом:

```json
{
  "name": "Московский марафон",
  "date": "09.08.2026",
  "upcoming": true,
  "place": "Moscow, Russia",
  "format": "Marathon",
  "distance": 42.2,
  "target": "3:30:00",
  "result": ""
}
```

Поля:
- `name` — название забега
- `date` — дата в формате `ДД.ММ.ГГГГ`
- `upcoming` — `true` для предстоящего забега (серый бейдж «Запланировано»), `false` для завершённого (зелёный бейдж «Завершено»)
- `place` — город и страна
- `format` — формат (Marathon, Half marathon, Local running event, 10k и т.д.)
- `distance` — дистанция в км
- `target` — целевое время в строковом формате, например `"3:30:00"`, `"50:00"`
- `result` — время финиша строкой (например `"3:59:12"`) или пустая строка `""`, если ещё не пробежал

### Регистрация файла

Добавьте имя файла в список в `run_results/manifest.json`:

```json
{
  "runs": [
    "новый-файл.json",
    "94748616-8f7a-47eb-affe-2d5b5121ad60.json",
    "853e2b8e-448f-4458-950c-de7534aca89e.json",
    "3076d610-4caf-418f-a578-2a8badd1a93f.json",
    "99b3adb2-1915-4cac-a875-086fb020267a.json"
  ]
}
```

### Формат времени

Время в JSON записывается строкой в формате `ЧЧ:ММ:СС` или `ММ:СС`:
- `"5:12:45"` → отображается как **5:12:45** (марафон)
- `"50:00"` → отображается как **50:00** (10 км)
- `"19:37"` → отображается как **19:37** (5 км)

Карточки забегов компактные: время финиша показывается только для завершённых забегов (зелёный бейдж и зелёное время), для предстоящих — серый бейдж «Запланировано» без времени.

### Сортировка

Карточки автоматически сортируются от новых к старым по дате.

## Локальный запуск (без сервера)

Сайт работает **без сервера** — просто откройте `index.html` в браузере двойным кликом (или через `file://`).

Забеги встроены прямо в `js/main.js` (массив `BUILTIN_RACES`), поэтому таблица забегов отображается сразу без каких-либо запросов.

### Как работает загрузка забегов

1. При открытии страницы JS сначала пробует загрузить `run_results/manifest.json` через `fetch()`.
2. На GitHub Pages fetch работает — забеги загружаются из JSON-файлов (удобно обновлять результаты без правки кода).
3. Если fetch недоступен (открытие через `file://`) или JSON не загрузился — используются встроенные данные из `BUILTIN_RACES` в `js/main.js`.

### Важно для file://

При обновлении результата забега через JSON-файл (`run_results/*.json`) на GitHub Pages эти данные подхватятся автоматически. При локальном открытии через `file://` обновления JSON не подхватываются — в этом случае обновите данные прямо в массиве `BUILTIN_RACES` в `js/main.js`.
